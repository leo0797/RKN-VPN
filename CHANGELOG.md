# Changelog

Все заметные изменения в проекте RKN VPN документируются в этом файле.

## [Unreleased]

## [1.0.27] - 2026-11-20

### Added
- Несколько профилей подписок с миграцией текущей подписки, переключением/добавлением/удалением/обновлением в настройках и резервным копированием без токенов.
- Избранные серверы (закрепляются сверху), фильтры по стране и протоколу, метка протокола на карточке и автопинг при открытии вкладки серверов.
- Настройка «Подключаться при запуске приложения» (по умолчанию выключена) с подсказкой про системный Always-on VPN.
- Режимы DNS: «Авто» с DoH, политикой для `.ru`/`.su`/`.рф` и fallback на system, а также Cloudflare/Google/пользовательский адрес.
- Просмотр состава готовых пресетов маршрутизации.
- Расширенная матрица эмуляторных smoke-тестов в CI.

### Changed
- Статус kill switch на главном экране теперь честно показывает ON/OFF/UNKNOWN с пояснением и действием.
- Кнопки в «Диагностике» выровнены по стилю.
- Проверка обновлений при сетевой ошибке повторяется через локальный прокси активного VPN, если он доступен.
- В CI debug-ключ генерируется автоматически; публичный `app/debug.keystore` не хранится в репозитории.

### Fixed
- При смене ключа подписи in-app обновление обрабатывает несовместимость установки и направляет на ручную установку; уточнена проверка подписи APK в документации.
- При ошибке расшифровки защищённых данных значение не удаляется без следа: показывается баннер «Данные подписки недоступны. Добавьте ссылку заново», флаг снимается после успешного добавления/обновления подписки.
- Исправлена совместимость CameraX с 16 KB page size на Android 15+: обновлены зависимости `androidx.camera` до 1.4.2, чтобы нативные библиотеки корректно загружались на API 35.

## [1.0.26] - 2026-11-20
### Fixed
- Исправлены аватары узлов с флагами и эмоджи: используется первый символ целиком вместо битого UTF-16 суррогата; вкладка «Серверы» корректно работает со скринридерами и UI-автоматизацией.
- Исправлена кнопка «Сохранить и обновить» в настройках: она больше не схлопывается и сохраняет ссылку на подписку.
