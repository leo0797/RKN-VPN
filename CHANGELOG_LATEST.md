Что нового в 1.0.23:

• Исправлен вылет на Android 12+ сразу после онбординга: чтение статуса системного kill switch теперь безопасно обрабатывает запрет доступа к скрытым настройкам. На устройствах, где системные настройки недоступны, статус показывает «выключен», не роняя приложение.

Если у вас уже стоит 1.0.22 — просто обновитесь, удаление не требуется. При переходе с версии старше 1.0.22 сертификат подписи отличается: удалите старое приложение перед установкой (настройки сохранятся в резервной копии). Это одноразовая процедура.

What's new in 1.0.23:

• Fixed a crash on Android 12+ right after onboarding: reading the system kill switch status now safely handles denied access to hidden settings. On devices where the system setting is restricted, the status shows "off" instead of crashing.

If you already have 1.0.22 installed, just update — no need to uninstall. When upgrading from a version older than 1.0.22, the signing certificate differs: uninstall the old app first (your settings will be restored from backup). This is a one-time step.
